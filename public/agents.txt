# Free discovery
Capability: resolve
Endpoint: POST https://agentresolver.vercel.app/api/resolve
Price: free
Read-only: true
Spending-authorized: false
Description: Resolve a missing external capability into ranked AgentResolver-owned tools, MCP services, and machine-service candidates. Use when no already-connected tool clearly satisfies the task.
